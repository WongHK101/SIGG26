\section{Method}

\subsection{Task Definition}

Given RGB and multispectral captures (G/R/RE/NIR), we seek a representation that supports both novel-view rendering and stable spectral product synthesis. Let $\mathcal{G}$ denote Gaussian support parameters (position, scale, rotation, opacity, identity) and $\mathcal{A}_b$ denote appearance parameters for band $b$. The key design choice in this work is to optimize $\mathcal{G}$ once from RGB, then hold $\mathcal{G}$ fixed while learning $\mathcal{A}_b$.

\subsection{Stage 1: RGB Geometry Anchor}

We first train an RGB Gaussian model with the standard 3DGS optimization pipeline~\cite{kerbl2023gaussiansplatting}. RGB is used as the anchor because it provides the highest texture and most stable feature matching in our UAV captures. The resulting checkpoint defines the shared support $\mathcal{G}^\star$ used by all spectral bands.

\subsection{Stage 2: Geometry-Locked Spectral Transfer}

\paragraph{E3 (independent transfer).}
For each band $b \in \{G,R,RE,NIR\}$, we initialize from $\mathcal{G}^\star$, freeze all support parameters, and optimize only $\mathcal{A}_b$. This yields four render-compatible spectral models sharing identical Gaussian topology by construction.

\paragraph{E4b-zero (joint band-bank transfer).}
We keep the same frozen $\mathcal{G}^\star$ but optimize four appearance banks in one joint training state. Training alternates active bands in a deterministic round-robin schedule, updates only the active bank, and writes one authoritative multispectral checkpoint. Per-band models are exported only for compatibility with existing render/metric scripts.

\paragraph{Representation invariants.}
For both E3 and E4b-zero we enforce and audit:
\begin{itemize}
    \item fixed Gaussian count and identity;
    \item fixed xyz/scale/rotation/opacity;
    \item appearance-only parameter updates in stage 2.
\end{itemize}
These invariants are the basis for index-stable shared support.

\subsection{Raw-Scene Rectification and Baseline-Aware QA}

Raw UAV scenes require spectral-to-RGB rectification before Stage 1. We estimate per-band homographies using deterministic candidate sampling and robust aggregation from feature matches. QA is baseline-aware:
\begin{itemize}
    \item \textbf{strict pass}: legacy edge+gradient improvement and geometry checks;
    \item \textbf{pass-with-warning}: allowed only for weak-baseline/high-modality-gap cases that satisfy match quality, stability, gradient gain, edge floor, and outlier-ratio constraints;
    \item \textbf{fail}: unstable geometry or insufficient matching evidence.
\end{itemize}
Estimator QA is an online gate; final standalone QA on exported rectified outputs is the authoritative decision.

\subsection{Products and Geometry Diagnostics}

We render G/R/RE/NIR and compute NDVI, GNDVI, and NDRE under a common valid mask. Geometry is evaluated by relative depth agreement on held-out probe views:
\[
\delta_{rel} = \frac{D_{model} - D_{ref}}{D_{ref}} .
\]
Because global metric scale is not guaranteed in raw UAV reconstructions, we report relative-depth AbsRel and threshold agreements (1\%, 5\%, 10\%) instead of meter-based absolute accuracy.
